Prime Hub V3 — Bulk Delivery Files + Sold Item Ledger

CUSTOMER BULK DELIVERY
- For 1-4 text items: normal Telegram delivery message.
- For 5 or more text items:
  * concise Telegram confirmation
  * downloadable TXT delivery file
  * downloadable CSV delivery file
- File-ID/document stock continues to be delivered normally.

ADMIN SOLD DATA
Command:
  /solddata

Filters:
- Today
- Yesterday
- Last 7 days
- Last 30 days
- Last 1 year
- Custom date range
- Specific Telegram user ID
- Specific @username
- Recent 100 sold items

CSV includes:
- delivered date/time
- order ID
- Telegram user ID
- customer name
- username
- product ID/name
- order quantity
- stock item ID
- exact delivered item
- payment method
- order amount
- delivery type

The existing /reports command is also activated for revenue, units,
customer performance and product performance.
