Prime Hub V3 — Bulk + Typed Quantity

Changes:
- Removed the fixed maximum of 13 units per order.
- Maximum order quantity is now the live available stock.
- Example: if stock is 90, the customer may order up to 90.
- Existing + / - quantity buttons remain.
- Added a "Type Quantity" button.
- Customer can type a number such as 25, 50, or 90.
- After a valid typed quantity, the bot goes directly to payment selection.
- If the typed quantity is above current stock, the bot asks for a lower quantity.
- Stock is still checked again when the order is created and again at delivery,
  protecting against simultaneous buyers.

Applies to:
- Prime Hub Wallet
- Binance manual payment
- UPI manual payment
- USDT TRC20 direct auto verification
- USDT BEP20 direct auto verification
